# Nord Night

A cool dark theme that blends the deep storm background of Tokyo Night with the
frosty arctic accents of Nord.

## Palette

| Role | Color |
| --- | --- |
| Background | `#1a1b26` (Tokyo Night Storm) |
| Foreground | `#d8dee9` (Nord snow storm) |
| Accent | `#88c0d0` (Nord frost) |
| Blue | `#7aa2f7` |
| Cyan | `#8fbcbb` |

## Install

Extensions → Themes → search **Nord Night** → Install.

Then set it in `settings.json`:

```json
{
  "theme": {
    "mode": "dark",
    "dark": "Nord Night"
  }
}
```
